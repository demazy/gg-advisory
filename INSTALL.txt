Install with the self-contained PATCH_GRANTS_RADAR_ZERO_API.sh script.

The installer:
1. verifies the target repository;
2. backs up every replaced file;
3. verifies the current canonical grants.yaml hash;
4. installs the complete v6 package including the hidden GitHub workflow;
5. migrates the known canonical baseline to the verified 2026-09-01 bootstrap registry;
6. verifies that no OpenAI/API-key dependency remains;
7. runs syntax checks, preflight and tests when local dependencies are present;
8. prints Git changes but does not commit automatically.
